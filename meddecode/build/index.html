How words are checked (for instructors)

Joining parts: the game joins the tiles for the student and follows the combining-vowel rules. The o of a root is kept before a consonant (hepat/o + -megaly = hepatomegaly) and between two roots (gastroenteritis), and dropped before a vowel (gastr/o + -itis = gastritis). When the next part starts with the same vowel a root ends in, one is dropped (cardi/o + -itis = carditis).

Real words: every build is looked up in MedDecode's word list, which includes the answer plus the real terms that can be made from each 12-tile tray. The trays were checked against a 660,000-word dictionary, and every medical term they can form is on the list; coincidental non-medical words (such as epi- + -ic = epic) are not. If a student builds a real term that doesn't answer the question, the game congratulates them on building a real word, gives its definition, and says clearly that it is not the answer. In Learn mode it also points to the part that doesn't fit the case. If the build isn't in the list, the game says it isn't a recognized term and checks the order of the parts. A rare real term that is missing from the list will be reported as not recognized, so add real terms to the list as instructors find them.

Learn mode shows each tile's meaning, reads the word's meaning as it is built (suffix first, then prefix, then roots), offers two hints, and allows unlimited checks. Test mode hides meanings and hints, gives 90 seconds and 3 checks per case, and scores the first correct check: 100 points on the first check, 50 on the second, 25 on the third.

Jeopardy: each board has 5 categories (chosen at random from 7) and 5 clues worth 100 to 500, easier terms at lower values. Clues are definitions from the MedDecode master list, so the board grows as terms are added. Each clue gets one build. Partial credit = answer parts in the right order ÷ the longer of the build or the answer, so extra tiles lower the score. Example: for gastritis, gastr/o + -algia earns half; gastr/o + -itis + -ectomy earns two-thirds. In Test mode each clue has 60 seconds, and whatever is on the rack when time runs out is scored. In Team mode, the team whose turn it is earns the points.

All cases, terms and meanings are drafts for instructor review.
